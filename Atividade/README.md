# 📘 Atividade — Condições e funções em C++

Três exercícios curtos para praticar a leitura de valores no terminal, a tomada de decisões com **estruturas condicionais** e a utilização de funções. Cada arquivo representa um programa independente, com uma situação simples para aplicar os conceitos.

## 🧩 Exercícios da pasta

| Código-fonte | Proposta | Conceitos em destaque |
|---|---|---|
| [`exercicio_01.cpp`](exercicio_01.cpp) | Informar se uma idade é menor que 18 anos ou não. | `cin`, `cout`, `if/else` |
| [`exercicio_02.cpp`](exercicio_02.cpp) | Conferir se um inteiro está entre **10 e 20**, incluindo os limites. | Função `void`, ponteiro, `&&` |
| [`exercicio_03.cpp`](exercicio_03.cpp) | Classificar um número como **positivo, negativo ou zero**. | `float`, `if/else if/else` |

## 💡 O que é praticado

O primeiro exercício toma uma decisão a partir da idade digitada. No segundo, uma função recebe o endereço de uma variável e verifica duas condições ao mesmo tempo. O terceiro usa uma sequência de alternativas para escolher a mensagem adequada ao valor informado.

A pasta também guarda os executáveis [01](exercicio_01.exe), [02](exercicio_02.exe) e [03](exercicio_03.exe), associados aos arquivos-fonte.
